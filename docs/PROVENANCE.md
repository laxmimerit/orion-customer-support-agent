# Provenance and release scope

Orion company copy, datasets, documents, original orbit logo and dashboard code were authored as fictional course resources. No real customer messages, private account records or third-party logos are included. Email and phone fixtures use example.com and the reserved fictional 555-01xx range.

Core data generation uses seed 20261030 and Python's standard library. Parquet exports in this release use PyArrow 25.0.1. The dashboard has no CDN or network dependency; it uses the system sans-serif font. Inter is the optional recommended brand font and is not bundled. Its upstream licence is SIL OFL; retrieve it from the official font source if installing it during the course.

The repository remains private. A public-use licence and third-party notices should be reviewed before the creator makes it public. Application dependencies, model weights and credentials are not bundled.

This is a teaching simulation. Templates and deliberate patterns make it reproducible; they do not establish production model accuracy, realised revenue, legal suitability or actual customer outcomes.
