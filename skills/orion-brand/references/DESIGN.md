# Orion visual system

Orion brings order to support work. The visual identity is precise, calm and readable at dashboard density.

## Tokens

Light canvas #F3F6F8; surface #FFFFFF; primary ink #152E3B; muted ink #526775; border #DCE5EA; primary teal #087F78; teal tint #E4F3EF; warning #9A5800; danger #B53342; blue #476EBA.
Dark canvas #10232E; surface #193440; ink #F4F8FA; muted ink #B5C8D1; accent #57CCB5.

## Typography and spacing

Use Inter (Google Fonts, SIL Open Font License); fallback to Arial, sans-serif. Body 14-16px; table 13-14px; section title 18-22px; page title 30px. Use tabular numerals for metrics. Spacing scale 4, 8, 12, 16, 24, 32, 48px. Surface radius 12px; input/button radius 6px. Use understated borders and no text glow.

## Components

Primary buttons use teal with white text. Cards have a white surface, subtle border and 24px internal spacing. Tables use quiet horizontal separators, aligned numeric columns and visible headers. Status badges include text. Charts use teal for the main measure, blue for comparison and amber/red only for meaningful warning/failure states. Axes and denominators must be explicit. A zero and unavailable data are different states.

## Logo

The original Orion ring mark combines an open circular orbit with a guiding point. Use the supplied SVG. Keep clear space equal to one quarter of mark width. Minimum icon size 16px. Do not stretch, add shadows or rotate the mark. Wordmark typography uses the system fallback when Inter is absent.

## Dashboard

Use a left navigation rail, compact global filters, four summary metrics and a strong primary time-series chart. Follow with category distribution, workload, SLA, satisfaction and a searchable ticket list. Mobile stacks content and keeps tables horizontally scrollable. Every visible number comes from the chosen dataset and filters.
